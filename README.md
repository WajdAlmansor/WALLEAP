# WALLEAP

WALLEAP is an iOS application designed to support safer and more independent money management for users who may require financial supervision, such as children or people with disabilities.

The app allows a caregiver or responsible person to monitor spending activity and receive notifications when unusual spending is detected or when the user is approaching their budget limit.

## Features

- Spending and balance monitoring
- Budget and daily spending limits
- Notifications for unusual spending activity
- Alerts when approaching budget limits
- Transaction history
- Caregiver account support
- User account and profile management

## Technologies

- Swift
- SwiftUI
- Xcode
